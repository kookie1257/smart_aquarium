# 🐠 Smart Aquarium AI Bio-Scanner

A high-tech Computer Vision project that turns a standard aquarium view into a futuristic **HUD (Heads-Up Display)**. Using AI-driven motion detection and stable tracking, this system identifies fish and provides detailed biological information through an interactive "Bio-Scanner" interface.

## ✨ Features
- **Futuristic HUD UI:** Premium dark-themed interface with high-tech "Bio-Scanner" aesthetics.
- **Real-Time Fish Detection:** Automatically identifies and highlights fish on screen.
- **Stable Tracking:** Assigns unique IDs to fish to ensure information stays consistent even as they move.
- **Interactive Bio-Panel:** Click on any fish to reveal detailed species information and facts.
- **Glassmorphism Effects:** Modern transparent UI panels with smooth fade-in animations.
- **Visual Feedback:** Pulse effects and scanline animations for a premium user experience.

## 🛠️ Technologies Used
- **Python:** Core programming logic.
- **OpenCV:** Real-time video processing and UI rendering.
- **NumPy:** Mathematical calculations for tracking and image processing.
- **JSON:** Metadata management for fish information.

## 🚀 How to Run
1. Ensure you have Python installed.
2. Install the required libraries:
   ```bash
   pip install opencv-python numpy
   ```
3. Run the application:
   ```bash
   python smart_aquarium.py
   ```

## 🎮 Controls
- **Left Click:** Select a fish to "Scan" and see details.
- **ESC:** Deselect the current fish.
- **Q:** Quit the application.
